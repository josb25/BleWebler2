Data and privacy

Last updated: 28 August 2026

About this site

BleWebler2 is published by the project maintainer josb25 on GitHub. Project questions can be submitted through the repository issue tracker. Please do not post private label contents or device identifiers in a public issue.

Hosting

The public web application is hosted by GitHub Pages. GitHub states that it logs and stores a visitor's IP address for security purposes, whether or not the visitor is signed in. Details about GitHub's processing and contact options are available in the GitHub Privacy Statement. The BleWebler2 maintainer does not receive GitHub's visitor logs.

Data kept on your device

Labels, templates, paper profiles and application preferences are saved in browser storage on the device you use. The service worker also caches application files so the installed web app can start offline. You can remove this information through the application's controls or your browser's site-data settings.

Printer access

Bluetooth, USB and serial access is requested only when you choose to connect a printer. The browser or operating system displays the device chooser and controls the permission. Label and print data is sent directly to the selected device.

Paper identification

When a connected printer reports an NFC or RFID paper identifier, BleWebler2 interprets supported identifiers locally on your device. Paper identifiers, printer details, label designs and label contents are not sent to the printer manufacturer.

External links

Following a link to GitHub or OpenTLP opens that provider's website. Their own privacy information applies after you leave BleWebler2.

Data requests

BleWebler2 does not receive the labels or preferences stored in your browser. The project maintainer has no access to GitHub Pages connection logs. Requests concerning those logs should be directed to GitHub using the contact options in its privacy statement.
